# hf26-week4

Project for the DEV **Hacktoberfest 2026 Open-Source AI Challenge, Week 4** (October 26-31, 2026):
"Build something with open-source AI at its core".

The project is built during the challenge week. Until then this repository only holds the ground rules:

- **Open-source AI at the core:** an open-weight model running locally (for example through Ollama's HTTP API on
  `localhost`), so personal data never leaves your computer.
- **Python standard library only:** no `pip install`; `python3 -m <module> --help` explains everything.
- **Tests run offline:** `python3 -m unittest discover -s tests -t .` with a fake local model server and small
  synthetic sample files in `samples/` (never real personal data).
